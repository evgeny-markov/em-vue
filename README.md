# siteVue — портфолио Евгения Маркова

Одностраничный лендинг-портфолио на **Vue 3 + Vite**. Контент на русском и английском, анимации на **GSAP** (загрузка с SVG-morph, scroll-сцены, горизонтальные проекты).

## Стек

- Vue 3 (Composition API, `<script setup>`)
- Vite 8
- Pinia
- vue-i18n (RU / EN)
- GSAP (ScrollTrigger, MorphSVG, SplitText)
- SCSS + BEM, Stylelint

## Требования

- Node.js `^20.19.0` или `>=22.12.0`
- npm (только npm, без yarn/pnpm)

## Локальный запуск

```bash
npm install
npm run dev
```

Сайт откроется на `http://127.0.0.1:5173/`.

## GitHub Pages

Прод: [https://evgeny-markov.github.io/em-vue/](https://evgeny-markov.github.io/em-vue/)

Деплой идёт автоматически из `main` через Actions (`.github/workflows/deploy-pages.yml`).  
В Settings → Pages источник должен быть **GitHub Actions**.

Локальная сборка как на Pages:

```bash
DEPLOY_PAGES=true npm run build
```

## Структура

```
src/
  assets/styles/     # SCSS: tokens, mixins, компоненты
  components/
    landing/         # секции лендинга
    loader/          # стартовый экран с SVG-morph
  composables/
  data/              # проекты, навигация
  i18n/
  locales/           # ru.json, en.json
  stores/
public/              # favicon и статика без сборки
dist/                # результат npm run build (на FTP уходит это)
```

## Деплой по FTP

Сайт — **статический SPA**. На сервере не нужен Node.js: достаточно залить содержимое `dist/` в корневую папку сайта на хостинге.

### 1. Собрать проект

```bash
npm install
npm run build
```

После сборки в `dist/` будут примерно такие файлы:

```
dist/
  index.html
  favicon.svg
  assets/
    index-….js
    index-….css
```

### 2. Что заливать по FTP

Заливайте **содержимое** `dist/`, а не всю папку репозитория.

| Заливать | Не заливать |
| --- | --- |
| всё из `dist/` | `src/`, `node_modules/`, `.git/`, `package.json` |

Типичные папки на хостинге (зависит от панели):

- `public_html/`
- `www/`
- `htdocs/`
- `httpdocs/`

Корень домена должен совпасть с корнем `dist/` — чтобы по адресу сайта открывался `index.html`.

### 3. Как залить

1. Откройте FileZilla / WinSCP / встроенный FTP в панели хостинга.
2. Подключитесь по данным хостинга: **хост**, **логин**, **пароль**, порт **21** (или SFTP **22**, если доступен — лучше SFTP).
3. Перейдите в корневую папку сайта.
4. Загрузите файлы из `dist/` (режим передачи для HTML/CSS/JS — **бинарный** / auto).
5. При обновлении сайта снова соберите `npm run build` и перезапишите файлы на сервере (особенно папку `assets/` — имена файлов меняются после каждой сборки).

### 4. Домены и DNS

Для этого проекта **достаточно одного домена** (или поддомена). Backend и отдельные API-домены не нужны.

| Что нужно | Пример | Зачем |
| --- | --- | --- |
| Основной домен | `example.ru` | адрес портфолио |
| Опционально `www` | `www.example.ru` | редирект на основной или наоборот |
| Опционально HTTPS | сертификат Let’s Encrypt в панели хостинга | безопасный доступ по `https://` |

**DNS у регистратора домена** (или у DNS-хостинга):

1. Создайте запись **A** для `@` (корень домена) → IP-адрес сервера хостинга.
2. При необходимости **A** или **CNAME** для `www` → тот же IP или на `@`.
3. Дождитесь обновления DNS (обычно от нескольких минут до 24 часов).
4. В панели хостинга привяжите домен к нужной папке (`public_html` и т.п.).
5. Включите SSL (Let’s Encrypt) и редирект HTTP → HTTPS.

Поддомен тоже подойдёт, например `portfolio.example.ru` — тогда A/CNAME только для `portfolio`.

### 5. Если сайт не в корне, а в подпапке

Если адрес будет вида `https://example.ru/portfolio/`, в `vite.config.js` задайте `base`:

```js
export default defineConfig({
  base: "/portfolio/",
  // …
});
```

Пересоберите и заливайте содержимое `dist/` уже в папку `portfolio/` на хостинге.

### 6. Проверка после выкладки

- Открывается `https://ваш-домен/`
- Есть favicon
- Работают секции и скролл-анимации
- Переключатель RU / EN
- На мобильном и десктопе вёрстка на месте
